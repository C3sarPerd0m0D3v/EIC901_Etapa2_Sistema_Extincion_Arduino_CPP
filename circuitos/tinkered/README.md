# Versiones Tinkered

Guardar **cada exportación en una subcarpeta distinta**. Ejemplos:
- `V1_Pulsadores/`: `src/main.cpp`, `src/config.h`, `wiring/wiring.json`, `schematic/main.sch`, `platformio.ini`, `.tinkered/project.json`.
- `V2_Interruptores/`: los mismos tipos de archivos de la segunda exportación.

Nunca mezclar V1 y V2 ni reemplazar la versión anterior. Tinkered permitió observar las 8 combinaciones de F; el motor eléctrico todavía necesita validación.
